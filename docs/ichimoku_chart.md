# Ichimoku Chart

The Ichimoku Chart provides a single-stock view of trend direction, support/resistance structure, and Tenkan–Kijun crossovers using the standard **9 / 26 / 52** settings on daily or weekly candles.

---

## Chart components

| Component | Calculation | Interpretation |
|---|---|---|
| **Tenkan-sen** | Midpoint of the 9-session high and low | Faster conversion line |
| **Kijun-sen** | Midpoint of the 26-session high and low | Slower base line |
| **Senkou Span A** | Tenkan/Kijun midpoint, projected 26 sessions | Faster cloud boundary |
| **Senkou Span B** | Midpoint of the 52-session high and low, projected 26 sessions | Slower cloud boundary |
| **Chikou Span** | Close plotted 26 sessions backward | Lagging price comparison |

The chart uses adjusted daily OHLC prices from the same local data store as the screeners.

### Cloud colors

- **Green cloud:** Senkou Span A is at or above Span B.
- **Red cloud:** Senkou Span A is below Span B.
- The cloud extends 26 trading sessions beyond the latest candle. This is an indicator projection, not a future-price forecast.

### Tenkan–Kijun crossovers

A green upward marker identifies a bullish cross, where Tenkan-sen moves above Kijun-sen. A red downward marker identifies a bearish cross.

Crossovers are classified using the cloud visible on the crossover date:

| Crossover | Above cloud | Inside cloud | Below cloud |
|---|---|---|---|
| **Bullish** | Strong | Neutral | Weak |
| **Bearish** | Weak | Neutral | Strong |

If the historical cloud is not yet available, the crossover is shown but its strength remains unclassified.

---

## Status and summary

The cards above the chart report the latest price position, Tenkan/Kijun alignment, latest valid crossover, and the cloud at the end of the forward projection.

The **Ichimoku Summary** below the chart is generated by deterministic rules. It describes only calculated conditions, may vary when the date or technical state changes, and does not make price predictions or trading recommendations.

---

## Controls

- **Timeframe:** switches between daily candles and true weekly OHLCV aggregation. In weekly mode, Ichimoku periods and crossover ages are measured in weeks.
- **Log Y-Axis:** displays proportional price moves consistently across long periods.
- **Show Chikou:** shows or hides the lagging span.
- **Show Crosses:** shows or hides crossover markers.

Enter an NSE symbol without the `.NS` suffix. If no exact symbol is found, the app suggests the closest constituent symbol.
